# المرشد الأكاديمي الذكي — جامعة فلسطين الأهلية
**Smart Academic Advisor (RAG) · IEEE RAG Hackathon @ Bethlehem University 2026**

مساعد يجيب عن أسئلة الطلبة الأكاديمية **من وثائق الجامعة الرسمية فقط**، بالعربية وباللهجة المحكية، ويذكر المصدر (الوثيقة + البند/القسم + الرابط) في كل إجابة، ويرفض بوضوح عندما لا تكفي الوثائق ويحيل إلى عمادة القبول والتسجيل.

## النتائج (eval/report_final.md · 15 سؤال اختبار بـ 7 أنواع)
| المقياس | Baseline | بعد التحسين |
|---|---|---|
| Retrieval Hit@4 | 42% | **92%** |
| MRR | 0.33 | **0.81** |
| دقة الإجابات | 73% | **87%** |
| رفض الأسئلة خارج النطاق | 100% | **100%** |
| دقة الاقتباس | 25% | **83%** |
| متوسط زمن الإجابة | 3.6 ث | **3.1 ث** |

**ما الذي حسّن النتائج (تحليل الأخطاء):**
1. مسارات Windows (`\`) لم تطابق `_meta.json` (`/`) → صفحات البرامج دخلت بلا عناوين. الإصلاح: `as_posix()`.
2. بيانات تجريبية اختلطت بالبيانات الحقيقية → عزلناها في `data/demo`.
3. أداة الجمع استبعدت صفحات البرامج لأنها في قائمة الموقع → صار الشرط: الصفحة تحتوي "الخطة الدراسية".
4. علامة «؟» العربية كانت تلتصق بآخر كلمة في السؤال (BM25) → إصلاح الـ tokenizer.

**ما زال يفشل (بصراحة):** p05 (اسم مساق مشترك بين عدة برامج — يحتاج النظام أن يسأل «أي برنامج؟»)، p08 (أقصى مدة للدراسة موجودة في ملف PDF ممسوح ضوئياً بلا نص → يحتاج OCR).

## المعمارية
```
موقع الجامعة (PDF + صفحات البرامج)
  → scripts/collect_paluniv.py   جمع 60 وثيقة رسمية + بيانات وصفية (عنوان، رابط، تاريخ)
  → rag/ingest.py                تنظيف (إزالة القوائم/الترويسات، NFKC، إصلاح العربي المقلوب)
                                 تقطيع حسب البنية (البند/العنوان) + كل مساق في الخطة = سجل مستقل
  → rag/index.py                 BM25 (عربي مطبّع + تجذيع خفيف) + متجهات multilingual-e5 (محلي)
سؤال الطالب (عربي/لهجة/إنجليزي)
  → rag/pipeline.py  understand  توسيع اللهجة + إعادة كتابة سؤال المتابعة بالسياق
                     retrieve    بحث هجين + دمج RRF + تفضيل الإصدار الأحدث + إزالة التكرار
                     gate        بوابة رفض قبل النموذج (تشابه + تغطية الكلمات)
                     generate    مصادر مرقمة + «أجب من المقاطع فقط» + اقتباس [n] + حماية من prompt injection
                     verify      التحقق من أرقام المصادر، خفض الثقة إن غابت
  → app/server.py                واجهة ويب RTL + API
```
**النماذج (كلها مجانية، لا API مدفوع):** LLM: `qwen/qwen3.8-27b` عبر Groq (مفتوح المصدر)، احتياطي تلقائي `openai/gpt-oss-120b` · Embeddings: `intfloat/multilingual-e5-small` محلياً · التبديل بسطر في `.env` (Gemini / Ollama محلي).

## التثبيت والتشغيل
```bash
python -m venv .venv && .venv\Scripts\activate        # Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env                                 # ضع GROQ_API_KEY (مجاني من console.groq.com)
python scripts/collect_paluniv.py                      # جمع الوثائق الرسمية (3-5 دقائق)
python -m scripts.build_index                          # بناء الفهرس (~4 دقائق على CPU)
python -m app.server                                   # http://localhost:8000
```
أدوات: `python -m scripts.ask "سؤال"` (الإجابات في answers.txt) · `python -m eval.run_eval --no-judge --pace 8` (التقييم) · `python -m scripts.calibrate` (معايرة عتبة الرفض). حساب المشرف من `.env`: `ADMIN_USER` / `ADMIN_PASSWORD`.

## ميزات المنتج
محادثة RTL بالعربية واللهجة · لوحة «الدليل من الوثائق» تعرض المقطع المقتبس مع رابط الوثيقة · إدخال صوتي (ar-PS) · شارة ثقة لكل إجابة · 👍/👎 · «كيف وصل المساعد للإجابة» · تسجيل دخول وحفظ المحادثات · لوحة إدارة: الأسئلة الأكثر تكراراً، **فجوات المعرفة**، رفع/حذف الوثائق مع إعادة فهرسة تلقائية، نتائج التقييم.

## الأمان والخصوصية
المفاتيح في `.env` فقط (مستثنى في `.gitignore`) · حجب الإيميل/الهاتف/رقم الهوية من السجلات · كلمات مرور مشفرة · rate limit · RBAC على مستوى الاسترجاع · لا بيانات شخصية لطلاب حقيقيين · مسار محلي بالكامل عبر Ollama للبيانات الحساسة.

## مصادر البيانات (عامة، من الموقع الرسمي paluniv.edu.ps)
دليل الطالب 2024-2025 و2023-2024 · الأنظمة واللوائح للقبول والتسجيل (?page_id=136966) · شروط منح درجة البكالوريوس (?page_id=136965) · الأسئلة الشائعة · قبول الطلبة الجدد · المنح والمساعدات · صفحات 48 برنامجاً (الخطط الدراسية ووصف المساقات) · نظام منح البكالوريوس/الدبلوم والنظام الأساسي (PDF ممسوحة). الروابط الكاملة في `data/docs/_meta.json`.

## إفصاح استخدام الذكاء الاصطناعي
استخدمنا Claude (Anthropic) للمساعدة في كتابة هيكل الكود والتوثيق وتصميم الواجهة. قرارات التصميم (التقطيع، بوابة الرفض، أسئلة الاختبار، اختيار النماذج) وتشخيص الأخطاء من نتائج التقييم قام بها الفريق، وكل عضو يستطيع شرح جزء من الكود. النموذج اللغوي داخل النظام: Qwen عبر Groq.

## Deliverables in this repo
- `docs/AcademicAdvisor_Slides.pdf` — presentation (12 slides) · `docs/slides.html` — present in Chrome (press F)
- `docs/AcademicAdvisor_Demo.mp4` — 2:17 demo video
- `storage/index/` — prebuilt index (4,460 chunks) so the app runs immediately; rebuild with `python -m scripts.build_index`
- The embedding model `intfloat/multilingual-e5-small` downloads automatically from Hugging Face on first run (~470 MB, not stored in git).
